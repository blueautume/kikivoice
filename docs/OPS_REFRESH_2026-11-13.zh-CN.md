# Kiki运维 1.0（2）更新与验收

日期：2026-11-13。分支：`codex/kiki-ops-update`。本轮仅将管理端构建号从 `1` 升至 `2`，营销版本仍为 `1.0`；KikiTalk 用户端保持 `1.1.2（51）`。

## 修复与交付

- 修复停留在社交举报页时，切后台再返回只剩筛选器的问题。页面恢复时重新校验权限并加载，后台、撤权、退出及切换服务继续隔离旧数据；未确认处置回执仍复用原请求编号。
- 自动恢复按当前可见页面和前台周期去重，防止 403 引发反复重读。保留手动刷新和空态重试提示。
- 修复问题记录提示支持公开编号、实际却只搜索内部编号的问题。服务器现在同时搜索记录时昵称、内部稳定编号及当前未注销用户缓存的公开号码；App 列表优先显示公开号码，详情明确区分公开与内部编号。
- 新增可选 `userDisplayID`，保持旧服务器响应、旧客户端及原 schema 兼容。不改数据库结构、不改写历史事件正文或哈希；未缓存、已注销或异常号码仍安全回退内部编号，公开号码不作为历史身份或处置目标。
- 更新“服务与会话”的社区管理说明，覆盖语聊举报和个人资料/私聊举报；实际包版本改为读取工程配置，避免固定在旧构建号。
