# KikiTalk 1.1.2（49）发布记录

日期：2026-11-13。开发分支：`codex/kiki-development`。

本轮按用户最新要求仅升级构建号：`MARKETING_VERSION` 保持 `1.1.2`，`CURRENT_PROJECT_VERSION` 从 `48` 升至 `49`。后续默认只递增构建号，除非用户明确要求升级版本号。最终归档已核验实际版本为 **1.1.2（49）**。

## 本轮优化

- 房间改为固定布局，移除麦位舞台的纵向滚动和底部渐隐。按未弹出键盘时的可用高度压缩间距、圆环与头像，关系图、图例、听众和右侧操作栏共享稳定的画布预算。
- 输入框与发送按钮使用独立原生键盘布局层，仅这两项随键盘升降；房间标题、关系图、模式选择器、图例、听众与右侧操作栏保持原位置，不再由键盘抬升大块空白或压缩主舞台。输入行增长和上麦邀请也不改变主舞台的高度预算。
- 模式选择器收为关系图右下方的紧凑控件，顺序统一为“八字／星座／MBTI”，图例继续展示当前体系的全部可见关系。
- 八字隐藏“无直接合冲”（`NONE`），只显示相合、相冲、合冲并见；MBTI 隐藏“其他组合”（`OTHER`）。连线、图例和关系说明同步过滤，旧关系码仍可解码，不将隐藏结果强行归入其他关系。
- 小屏与多人场景根据实际昵称、公开标签和头像边界调整标签位置，避免长昵称、MBTI 或星座盖住相邻头像。头像和关系端点保持共同的平滑移动，移开的标签仍属于原用户的资料点击区域。
- 修复原生输入框异步焦点回写覆盖较新收起意图的问题，避免键盘收起后再次被旧状态打开。

本轮没有修改配对分类算法、分值或服务端排盘。客户端继续使用服务端返回的公开关系结果；真太阳时、出生地、自动历制及星座计算沿用现有服务端实现。八字只在服务端计算，原始出生资料和四柱仅本人可见，其他用户只能查看关系结果；MBTI 和星座的公开规则保持不变。协议继续为 `2026-11-13-r18`，没有新增资料确认或公开开关。“赛博算命”参考项目未修改。

## 服务端实际发布

本轮为纯 iOS 客户端更新，**不部署或重启任何服务器服务**，不替换后端、官网、协议或服务器配置。现有账号、语聊和陪玩管理台 `batty-club.service` 均不在本轮发布范围；不操作陪玩管理台的进程、版本指针、配置或业务数据。

工作区原有其他项目的 53 个文件保留原内容及权限，不纳入本轮提交或发布。服务器上保留现有算法与隐私边界；本轮界面变化需要安装新版 App 才能生效，不能通过服务器发布代替客户端更新。
