# KikiTalk 1.1.2（48）发布记录

日期：2026-11-13。开发分支：`codex/kiki-development`。

## 本轮优化

- 连线改为轻微弯曲，常规长度的中点弯曲不超过 10pt。“合冲并见”的两条线分到头像连弦两侧，中段间距约 20pt；短连接按空间缩小弯曲，维持明确间隔。
- 八字模式不保留昵称下的空标签和大块底衬；切换 MBTI／星座时，标签淡入并平滑展开。头像锚点和关系端点保持稳定，默认头像继续使用不透明底色。
- 修复未上麦、空聊天及大圆环时右下角按钮被裁切的问题。完整按钮栏使用 94pt 高度，舞台不会重复多占用预留空间，极小视口仍可滚动查看末尾麦位。
- 房间使用统一连续背景，舞台溢出底边柔和过渡，消除输入框上方的硬边遮盖；输入区继续正常避让键盘。
- 三种体系共 17 类说明同步改为简短娱乐文案。当前配对优先显示“谁与谁”和“默契合拍”“欢喜冤家”“互补来电”等标题，再用两句解释相处感觉；原关系名与线图保留供对照。

配对分类、算法和分值未改。八字仍只在服务端计算，原始出生资料和四柱仅本人可见；协议保持 `2026-11-13-r18`，本轮没有新增资料确认或公开开关。“赛博算命”参考项目未修改。
